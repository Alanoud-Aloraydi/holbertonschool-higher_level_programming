# Python - Everything Is Object

This project explores Python's object model, including identity, equality,
references, aliases, mutable and immutable objects, argument passing, object
copying, constant reuse, small integer caching, and string interning in CPython.

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- pycodestyle 2.7.x

## Files

Text files contain one-line answers to object-model questions. Python scripts
implement list copying, persistent function state, and restricted instance
attributes.
