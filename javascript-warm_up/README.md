# JavaScript - Warm Up

This project introduces JavaScript scripting with Node.js. It covers variables,
constants, data types, command-line arguments, conditionals, loops, functions,
objects, recursion, and modules.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard 16.x.x
- Every script starts with `#!/usr/bin/node`
- Every script is executable
- `var` is not used

## Files

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints a message using a constant. |
| `1-multi_languages.js` | Prints three programming-language messages. |
| `2-arguments.js` | Reports the number of supplied arguments. |
| `3-value_argument.js` | Prints the first supplied argument. |
| `4-concat.js` | Builds a sentence from two arguments. |
| `5-to_integer.js` | Converts the first argument to an integer. |
| `6-multi_languages_loop.js` | Prints an array of messages with a loop. |
| `7-multi_c.js` | Prints `C is fun` a requested number of times. |
| `8-square.js` | Prints a square made of `X` characters. |
| `9-add.js` | Adds two command-line integers with a function. |
| `10-factorial.js` | Computes a factorial recursively. |
| `11-second_biggest.js` | Finds the second-largest argument. |
| `12-object.js` | Updates a property of an object. |
| `13-add.js` | Exports an addition function. |
