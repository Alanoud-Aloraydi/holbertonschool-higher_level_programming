# SQL - Introduction

## Description
This project introduces the core concepts of relational databases, focusing on basic SQL (Structured Query Language) commands. It covers both Data Definition Language (DDL) and Data Manipulation Language (DML) operations using MySQL 8.0.

## Learning Objectives
* Understanding the concept of databases and relational databases.
* Executing basic SQL operations: `CREATE`, `ALTER`, `SELECT`, `INSERT`, `UPDATE`, and `DELETE`.
* Managing databases and tables in MySQL.
* Utilizing basic MySQL functions and writing subqueries.

## Environment & Requirements
* **OS:** Ubuntu 22.04 LTS
* **Database Engine:** MySQL 8.0 (version 8.0.25)
* **Syntax:** All SQL keywords are written in UPPERCASE. Every query is preceded by an explanatory comment.
