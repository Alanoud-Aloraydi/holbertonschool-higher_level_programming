# JavaScript DOM Manipulation

This project introduces client-side JavaScript through direct interaction with
the Document Object Model (DOM). Its scripts select and update elements, respond
to user events, create and remove list items, and retrieve remote data without
reloading the page.

## Learning objectives

- Select elements by ID, class, and tag name.
- Update element styles, classes, and text content.
- Create, append, and remove DOM nodes.
- Register event listeners for user and document events.
- Retrieve and display JSON data with the Fetch API and promises.

## Requirements

- Chrome 57 or later.
- Semistandard-compliant JavaScript.
- `const` and `let` instead of `var`.
- DOM updates and network requests without page reloads.
- A trailing newline in every file.
