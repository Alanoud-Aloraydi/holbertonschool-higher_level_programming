# JavaScript DOM Manipulation

## About

Practice project for manipulating the DOM with vanilla JavaScript. Each
script selects elements, updates styles/classes/text, reacts to click
events, or fetches remote data — all without reloading the page.

## Technologies

- JavaScript (ES6+), no framework
- DOM APIs and the Fetch API
- semistandard (linting)
- Google Chrome 57+

## Files & Tasks

| File | Task |
| --- | --- |
| `0-script.js` | Set the header color to red on page load. |
| `1-script.js` | Change the header color to red on click. |
| `2-script.js` | Add the `red` class to the header on click. |
| `3-script.js` | Toggle the header between `red` and `green`. |
| `4-script.js` | Add a list item on click. |
| `5-script.js` | Replace the header text on click. |
| `6-script.js` | Fetch and display a Star Wars character. |
| `7-script.js` | Fetch and list Star Wars movie titles. |
| `8-script.js` | Fetch and display a French greeting. |
| `100-script.js` | Add, remove, and clear list items. |
| `101-script.js` | Translate the greeting by a chosen language code. |

## How to Run / Test

Open the matching HTML test file in Chrome and interact with the buttons —
no build step is needed. To check style compliance:

```sh
npx semistandard *.js
```

## Requirements

- Google Chrome 57 or later
- Node.js + npm (only needed to run semistandard locally)
