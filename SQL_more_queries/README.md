# SQL - More queries

## Description
This project dives deeper into SQL concepts. It covers user privileges management, constraints (PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE), and retrieving data from multiple tables using JOINs, subqueries, and UNIONs in MySQL 8.0.

## Learning Objectives
* How to create a new MySQL user and manage their privileges.
* Understanding and implementing PRIMARY KEY and FOREIGN KEY constraints.
* Using NOT NULL and UNIQUE constraints in tables.
* Retrieving data from multiple tables in a single request.
* Writing subqueries and utilizing different types of JOINs.
