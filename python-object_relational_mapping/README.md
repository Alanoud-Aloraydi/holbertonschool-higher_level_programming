# Python - Object-relational mapping

## Description
This project links databases and Python using two approaches:
1. Low-level DB-API using `MySQLdb` to execute raw SQL queries.
2. High-level ORM using `SQLAlchemy` to abstract the storage logic and treat tables as Python Objects.

## Technical Objectives
* Connect to a MySQL database from a Python script.
* Select and insert data safely to prevent SQL Injections.
* Map a Python Class to a MySQL table using SQLAlchemy.
* Execute CRUD operations without writing explicit SQL syntax.
